# Interface: WatchHandle

Handle for watching a directory in the sandbox filesystem.

Use [WatchHandle.stop](#stop) to stop watching the directory.

## Methods

### stop()

> **stop**(): `Promise`\<`void`\>

Stop watching the directory.

#### Returns

`Promise`\<`void`\>
