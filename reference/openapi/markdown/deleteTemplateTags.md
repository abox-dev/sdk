# DELETE /templates/tags

Delete template tags

Delete multiple tags from templates

## Request body

Required: yes

### application/json

Schema: `DeleteTemplateTagsRequest`

- **`name`** · `string` · required

  Name of the template

- **`tags`** · `array<string>` · required

  Tags to delete

## Responses
