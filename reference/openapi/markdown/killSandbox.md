# DELETE /sandboxes/{sandboxID}

Kill sandbox

Kill a sandbox

## Parameters

| Name | In | Required | Type | Description |
| --- | --- | --- | --- | --- |
| `sandboxID` | path | yes | `string` |  |

## Responses

### 204
